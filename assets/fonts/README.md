# Embedded fonts

`../css/fonts.css` carries **Baloo 2** and **Comic Neue** as base64-encoded WOFF2
(latin and latin-ext subsets). They are embedded rather than linked so the game
works with no network access under the `file://` protocol.

| Family | Designer | License |
|--------|----------|---------|
| Baloo 2 | Ek Type | SIL Open Font License 1.1 — [OFL-Baloo2.txt](OFL-Baloo2.txt) |
| Comic Neue | Craig Rozynski, Hrant Papazian | SIL Open Font License 1.1 — [OFL-ComicNeue.txt](OFL-ComicNeue.txt) |

The OFL permits redistribution, including embedding, provided the licence and
copyright notice travel with the font. That is what these files are for — keep
them alongside `fonts.css`.
